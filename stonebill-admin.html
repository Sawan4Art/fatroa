دخول المالك

سجّل دخولك بحساب المالك (الإيميل وكلمة السر اللذين أنشفتهما في Firebase Console → Authentication → Users). هذا الحساب هو الوحيد المخوّل بإدارة الاشتراكات.

توليد كود تفعيل جديد

كود التفعيل — أرسله للمشترك على واتساب مع بريده:
دورة البيع الكاملة (دقيقتان):
1) المشترك يحوّل على فودافون كاش 01090042368 ويبعت الإيصال واتساب.
2) تؤكد وصول التحويل → تولّد كوداً ببريده من هنا.
3) تبعتله الكود واتساب → هو يفعّل من داخل التطبيق (الاشتراك والترخيص) بكود + بريده.
4) الكود يعمل على جهاز واحد فقط — لو غير موبايله يسجّل دخول جوجل بنفس بريدك المسجّل له أو تحرر جهازه من لسان «المشتركون».

إعداد Firebase — مرة واحدة فقط

1) افتح console.firebase.google.com → مشروعك.
2) Firestore Database → لو مش مفعّل: «Create database» → Production → أي منطقة قريبة (europe).
3) تبويب Rules → امسح الموجود والصق النص اللي تحت → Publish.
4) Authentication → Get started → Email/Password → Enable.
5) Authentication → Users → Add user → اكتب بريد المالك وكلمة سر قوية (هذا حساب دخولك هنا).
6) ارجع هنا وسجّل دخول.

قواعد الأمان — انسخها كاملة في Firestore → Rules
